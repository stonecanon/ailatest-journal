# AILatest Journal · Android 原生客户端 UI 规范

> 目标：不是把网站塞进手机，而是 **系统级原生 App**。  
> 语言锚点：Apple HIG（大标题 / Tab Bar / Sheet）+ 微信小程序现有 IA + 高星 skill（`android-ios-minimal` / TickTick 底栏 / To Do 列表简洁度）。  
> 视觉气质：保持知刊纸色/墨绿学术感，但 **控件与导航完全原生**。

---

## 1. 产品定位（移动端）

| 场景 | 能力 |
|------|------|
| 通勤 / 会后 | 秒查 IF / 中科院 / 预警 |
| 定刊决策 | 荐刊、对比 2–3 本 |
| 轻收藏 | 清单、稍后看（Pro） |
| 不负责 | 桌面级 40 维筛选全表、复杂侧栏、多地区站钉选 |

**原则：一屏一事，拇指区优先，少字多徽章。**

---

## 2. 信息架构（Bottom Tab · 4 项）

```
┌─────────────────────────────────────┐
│  查刊  │  荐刊  │  收藏  │  我的   │
└─────────────────────────────────────┘
```

| Tab | 角色 | 对应小程序 |
|-----|------|------------|
| **查刊** | 首页大搜索 + 结果列表 + 快捷筛选 | `pages/index` search |
| **荐刊** | 题目/摘要输入 → 结果梯队 | `pages/index` pick |
| **收藏** | 清单 + 期刊行（Pro 解锁，Free 引导订阅） | `pages/favorites` / `folder` |
| **我的** | 账号、订阅、插件/下载入口、设置 | `pages/profile` |

**不做：** 汉堡主导航、桌面三栏、把「全球/中国/榜单」全塞进底栏。  
榜单、地区站：放在查刊页 **次级入口**（顶部胶囊或「更多」Sheet）。

## 3. 设计语言（iOS 形 · 安卓实现）

### 3.1 布局与层级

| Token | 值 | 说明 |
|-------|-----|------|
| 背景 | `#F2F2F7`（浅）/ `#000000`（深） | iOS grouped 背景，非网站纸纹铺满 |
| 卡片面 | `#FFFFFF` / `#1C1C1E` | inset grouped |
| 圆角 | 12–14 pt 卡片 · 20 pt Sheet | |
| 列表行高 | ≥ 56 pt | 拇指友好 |
| 触控 | ≥ 44×44 pt | HIG |
| 主色 | `#1F5F4A`（墨绿，品牌） | 单一 tint，不用彩虹 |
| 强调 | `#C4A35A`（浅金，订阅/Pro） | 仅付费与关键 CTA |
| 字体 | 系统中文（思源/MiSans 可选） | **大标题 28–34** · 正文 15–17 · 次要 13 |

### 3.2 导航

1. **Large Title**：查刊 / 荐刊顶栏可折叠大标题（滚动后收成小标题）。
2. **Bottom Tab Bar**：固定 4 项，选中用主色图标填充 + 文字。
3. **详情 = Bottom Sheet**（中高档）：期刊详情从底部拉起，不是二级网页。
4. **筛选 = 半屏 Sheet / 水平 Chip**：不是侧边栏。

### 3.3 反模式（禁止）

- 桌面表格列（IF/JCR/中科院并排挤在一行小字）→ 改成 **徽章行 + 指标格**
- 顶部塞满 6 个地区按钮
- 用 WebView 包一整站当 App
- 28px 小星标、密集顶栏工具条

## 4. 关键界面

### 4.1 查刊（Home）

```
[ 大标题：查刊 ]
[ 搜索栏：期刊名 / ISSN / 学科     🔍 ]
[ 胶囊：全部 · SCIE · 中科院1区 · 预警 · 更多 ]
───────────
推荐 / 结果
┌ 期刊卡片 ─────────────────────┐
│ Nature  ·  ★                  │
│ IF 64.8  JCR Q1  中科院 1区    │
│ SCIE · 审稿约 3 月             │
└───────────────────────────────┘
```

- 搜索栏：**圆角 14、白底、系统键盘「搜索」**
- 结果卡：左 logo 缩写圆、右星标（Pro）、中下 4 指标格（对齐小程序 `metric-row`）
- Free：发表费用字段隐藏；星标点按 → 订阅 Sheet

### 4.2 荐刊（Pick）

```
[ 大标题：荐刊 ]
[ 多行输入 200 字 ]
[ 主按钮：开始推荐  满宽 50pt 墨绿 ]
[ 可选 Chip：SCIE · SSCI · 排除综合 ]
───────────
梯队 A / B / C 分组列表（inset）
```

- 一次任务流：输入 → 加载 → 结果；历史记录在顶部「最近」横向条
- AI 额度角标放在主按钮旁（如 今日 3/5）

### 4.3 收藏

- Free：空状态插画 + **升级 Pro** 金色按钮
- Pro：清单分段控件（默认 / 自定义）+ 可拖排序（Max 可更强）
- 导出：Sheet 选 RIS / Zotero / Notion（Pro）

### 4.4 我的

```
头像 / 邮箱
当前方案：Free | Pro | Max
[ 管理订阅 ]  [ 教育认证 ]

──── 工具 ────
下载插件 / Skill
原文查找余量 12/30
语言 · 外观 · 关于
```

### 4.5 期刊详情 Sheet

- 拖柄 + 刊名大字 + 徽章流
- 分段：概览 | 指标 | OA（Pro）| 相关
- 底栏固定：收藏 · 分享 · 官网（系统浏览器）

## 5. 与小程序 / 网站差异

| | 网站 | 小程序（现状） | Android 原生 |
|--|------|----------------|--------------|
| 导航 | 左侧 rail | 页栈 | **底栏 4 Tab** |
| 查刊表 | 全表筛选 | 卡片列表 | 卡片 + Chip |
| 详情 | 抽屉/路由 | 独立页 | **Sheet 优先** |
| 收藏 | 多清单工作流 | 有 | Pro 起，移动精简 |
| 风格 | 纸色学术 web | 浅灰卡片 | **iOS grouped + 墨绿品牌** |

共享：**数据 API、徽章语义、荐刊逻辑、会员权益**。  
不共享：**布局壳、侧栏、桌面表格。**

## 6. 技术建议（实现层）

| 方案 | 说明 |
|------|------|
| **推荐 A** | Kotlin + Jetpack Compose，Material 3 壳 + 自绘 iOS-like Tab/Large Title |
| **推荐 B** | Capacitor/Compose 混合仅作壳，核心列表仍原生 |
| 数据 | 复用 `api.ailatest.org` + 本地 SQLite 缓存热刊 |
| 登录 | 邮箱码 / OAuth，与网页同一账号 |
| 推送 | 可选：收藏刊预警变更（后期） |

首版范围（MVP）：

1. 查刊搜索 + 详情 Sheet  
2. 荐刊基础（日额度）  
3. 登录 + Free/Pro 权益门闸  
4. 收藏读/写（Pro）  
5. 我的 + 订阅页（WebView 或原生定价）

## 7. 视觉参考帧（实现验收）

- [ ] 冷启动 3 秒内可搜  
- [ ] Tab 切换无整页闪白（保留列表状态）  
- [ ] 详情 Sheet 可下拉关闭，背景列表不丢  
- [ ] 深色模式可读（对比度 AA）  
- [ ] Free 点收藏/导出出现订阅 Sheet，可关闭  
- [ ] 无桌面侧栏残影、无汉堡作为唯一导航  

---

## 8. 文案语气

- 按钮：短动词（搜索、开始推荐、升级 Pro）  
- 空状态：一句说明 + 一个主 CTA  
- 不在 App 里写内部成本/API 话术
