Features

功能介绍

检索全球期刊，对比分区、影响因子与开放获取信息 — 一站完成。库、分区、风险信号、荐刊与插件徽章在同一条工作流里。

◎
全球与地区期刊库SCIE / SSCI / AHCI / ESCI / EI、Scopus、DOAJ、MEDLINE；中国、印度、韩国、马来西亚等地区站。
▣
分区 · 指标 · 风险JCR 影响因子与 Quartile、中科院分区（含 TOP）、CCF / ABDC / ABS；预警与撤稿提示。
★
收藏与清单登录后云端收藏、多清单整理；对比时随时回看目标刊。
AI
智能荐刊输入论文标题 / 摘要 / 关键词，按主题与库覆盖匹配目标期刊（搜索框切到「荐刊」）。
⌘
浏览器插件Scholar / PubMed / 知网等页面展示分区与收录徽章，少开一个标签页。
↔
开放获取与 APCOAJ / DOAJ 信号与是否可免费发表路径（按订阅档位展示深度字段）。
How it works

怎么用

从打开首页到定稿目标刊，四步走完。

01搜索或荐刊刊名 / ISSN 直接查；或切换「荐刊」贴标题摘要。
02筛选分区与库按 JCR、中科院、索引、学科收窄候选列表。
03看详情与风险影响因子、审稿周期、OA / 预警信息一页看清。
04收藏或导出加入清单；插件在阅读页继续对照徽章。
