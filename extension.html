下载插件 ZIP

文件大小约 43KB。插件会请求 journal.ailatest.org 的期刊数据接口；匿名试用额度有限，登录后可获得更高查询额度。

稳定、安全、无流量劫持

AILatest 插件按生产力工具标准设计：核心查询依赖自有云端接口与本地缓存，目标是让高频检索时的徽章识别更稳定，减少因为第三方页面变化或接口波动造成的中断。

插件只为期刊识别请求必要数据，不上传浏览记录、检索关键词或论文阅读内容；不会注入广告、劫持优惠券链接、改写跳转或出售匿名流量数据。正式上架 Chrome Web Store 时，我们会按商店要求完整披露 Privacy Practices。

安装方式

  1. 下载 ZIP 并解压到本地文件夹。
  2. 打开 Chrome 或 Edge 的扩展管理页。
  3. 开启“开发者模式”。
  4. 点击“加载已解压的扩展程序”，选择刚才解压出的文件夹。
  5. 打开 Google Scholar、PubMed 或知网页面查看期刊徽章。
内测 ZIP 不会自动更新。正式版后续会以上架 Chrome Web Store 为准；商店版发布后，用户会通过浏览器自动更新。内测期间若某些站点没有识别出期刊，请下载本页新版或把页面链接发给我们。

A small beta release for compatibility testing and feedback. On Google Scholar, PubMed, CNKI and other literature pages, it shows journal IF, CAS tiers, JCR quartiles, indexed databases and domestic ranking badges directly beside each result.

AILatest Journal Extension beta v0.2.9

The current release is a manual Chrome / Edge installation package. It is not the final Chrome Web Store version yet, so it is intended for early testing, compatibility feedback and journal recognition fixes.

Download and unzip the package, enable Developer mode in the browser extension page, then load the unzipped folder.

Download extension ZIP

File size is about 43KB. The extension queries journal.ailatest.org for journal data. Anonymous trial quota is limited; signing in provides a higher quota.

Stable, safe and no traffic hijacking

AILatest is designed as a research productivity tool. Core lookup uses our cloud API and local cache to make high-frequency journal recognition more stable when third-party pages or interfaces change.

The extension only requests the fields needed for journal recognition. It does not upload browsing history, search keywords or reading content. It does not inject ads, rewrite links, hijack coupons or sell anonymous traffic data. When the Chrome Web Store version is released, we will publish complete Privacy Practices disclosures.

How to install

  1. Download the ZIP and unzip it to a local folder.
  2. Open the extension management page in Chrome or Edge.
  3. Turn on Developer mode.
  4. Click "Load unpacked" and choose the unzipped folder.
  5. Open Google Scholar, PubMed or CNKI to check the journal badges.
The beta ZIP does not update automatically. The final release will be published through the Chrome Web Store, where the browser can update it automatically. During beta testing, if a site or journal is not recognized, download the latest version here or send us the page link.
