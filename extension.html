在 Google Scholar、PubMed、知网页面直接显示期刊 IF、JCR、中科院分区、索引收录、国内目录和预警信息。

AILatest Journal Chrome Extension

当前版本：v0.2.0。当前用户默认使用 Free 版本；Pro 和 AI Credits 付费通道接入后开放。

下载插件 ZIP

插件 lookup API 使用 https://api.ailatest.org；开放全文按钮仅查找 Scholar 已有 PDF 和 OpenAlex 公开 OA 来源。

安装方法

  1. 下载 ZIP 后解压。
  2. 打开 Chrome 地址栏输入 chrome://extensions。
  3. 打开右上角“开发者模式”。
  4. 点击“加载已解压的扩展程序”，选择解压后的 extension 文件夹。
  5. 访问 Google Scholar、PubMed 或知网结果页，即可看到期刊徽章。
