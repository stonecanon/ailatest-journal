# AILatest Journal · 知刊

AILatest Journal is a bilingual academic-journal search and submission-planning platform for researchers.

**Live site:** [journal.ailatest.org](https://journal.ailatest.org)

## What you can do

- Search journals by title, abbreviation, ISSN, subject, indexing status, and open-access information.
- Compare journal indicators, review-cycle information, APC notes, warnings, and submission references.
- Build synchronized favorites and submission lists after signing in.
- Use the bilingual Chinese / English interface and install the PWA.

## About this repository

This is the public project page for AILatest Journal. It provides the project description, public links, and community entry point.

The production source and restricted or licensed data are maintained separately. Cloudflare deploys the production site from the private source repository.

## Data and privacy

- User accounts, payment records, and API keys are not stored in this repository.
- Restricted or licensed journal datasets are not redistributed here.
- Public site content is provided for research and submission-planning reference; always verify current requirements with the journal or publisher.
